# GLOVAL CRM - 株式会社GLOVAL 営業管理プラットフォーム

株式会社GLOVALの営業チーム（**黒川 剛様**、**奥中 佑亮様**、**屋木 孝之様**）専用に構築された、完全無料・ゼロランニングコストの自立型SFA/CRMプラットフォームです。

---

## 🔒 セキュリティ（合言葉による保護）
外部URLや社内ネットワークからの不正アクセスを防ぐため、**3名共通の合言葉（パスワード）**で保護されています。

- **初期合言葉**: `gloval`
- **自動ログイン**: 「この端末を記憶する」にチェックを入れてログインすれば、次回以降は入力不要です。
- **合言葉の変更**: 画面右上の「⚙️ 管理」→「合言葉の変更」からいつでも自由に変更できます。

---

## 🚀 毎日の起動方法（完全自動・スリープ防止対応）

フォルダ内の **`start_crm.command`** をダブルクリックするだけです。
1. **Macのスリープ防止（caffeinate）** が自動で有効化され、画面を閉じたり放置していても外出先から途切れません。
2. **ローカルサーバー** と **外出先用トンネル（Cloudflare Tunnel）** が同時に起動します。
3. 規定のブラウザで自動的にCRM画面が開きます。

### アクセス方法
* **スマホ・外出先（4G/5G回線・自宅など）**:
  画面右上の **「共有・スマホ」** ボタンを押すと表示される **QRコードをスマホカメラで読み取るだけ** で即座にアクセスできます。
* **自身のMac**: [http://localhost:8088/](http://localhost:8088/)
* **社内オフィスWi-Fi**: [http://192.168.128.73:8088/](http://192.168.128.73:8088/)

> **終了方法**: 作業を終えたい時は **`stop_crm.command`** をダブルクリックすると安全に一括停止します。

## 💾 データの安全性・自動バックアップ（安心設計）

1. **自動日次バックアップ**:
   起動時および日付が変わるごとに、`backups/crm_backup_YYYY-MM-DD.db` に自動バックアップが作成されます。
2. **ワンクリック即時ダウンロード**:
   右上の「⚙️ 管理」→「データ即時バックアップ」を押すと、最新のSQLiteデータベース（全データ）を手元に即座に保存できます。
3. **CSVエクスポート**:
   顧客一覧・案件一覧をExcel互換のCSV（UTF-8 BOM付き）でいつでもダウンロード可能。

---

## 🚀 本番運用の開始（デモデータの整理）

右上の「⚙️ 管理」メニューから：
* **デモデータを消去して本番スタート**:
  黒川様・奥中様・屋木様の3名のアカウントはそのまま保持した状態で、サンプルの案件・顧客・活動メモを綺麗に全消去し、真っ新な状態で実務を開始できます（実行前に自動バックアップが取られます）。
* **デモデータの初期リセット**:
  操作確認やテストを行いたい場合は、いつでも初期サンプルデータを復元できます。

## 📱 スマートフォンでの使いやすさ（モバイル最適化）

- **モバイルボトムナビ**:
  スマートフォンで開くと、画面下部に専用のナビゲーションバー（📊ダッシュボード、📋案件、📅カレンダー、🏢顧客、🗓️活動）が表示され、移動中でも片手でサクサク操作できます。
- **ホーム画面追加**:
  Safariの「共有」→「ホーム画面に追加」またはChromeの「アプリをインストール」で、スマホネイティブアプリのように全画面で起動できます。

## 🌟 主な機能一覧

1. **営業カレンダー**:
   - Web商談・顧客訪問・電話連絡・次回ToDo期日・案件クローズ予定日を月間グリッドで可視化。
   - 日付をタップすると右側にその日のスケジュールとToDoリストが展開。
2. **商談パイプライン（カンバン）**:
   - リード獲得 → 初回商談 → 提案・見積 → 最終交渉 → 受注 / 失注
   - ドラッグ＆ドロップで直感的に進捗管理。
3. **顧客マスター & 詳細スライド**:
   - 会社名をクリックすると、担当者情報、進行中案件、過去の商談タイムラインがひと目で展開。
   - CSV一括インポート機能付き。
4. **売上ダッシュボード**:
   - 受注確定額、確度加重見込（パイプライン金額 × 受注確率%）、3名の進捗状況をリアルタイムグラフ表示。
